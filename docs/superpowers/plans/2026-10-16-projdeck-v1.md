# projdeck v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `proj` command for macOS (works on Linux too) that aggregates projects, git status, staleness and Claude Code sessions from the Mac and several SSH hosts, and lets the user jump into a project or resume a session in a new iTerm2 tab, plus a reversible cleanup of stray untracked files.

**Architecture:** One standalone, stdlib-only script `projdeck/agent.py` runs on every host (piped over `ssh host python3 - '<json>'`) and answers JSON requests (`collect`, `list`, `trash`, `batches`, `restore`, `purge`). The Mac side (`config`, `sync`, `model`, `report`, `opener`, `ui`, `cli`) caches each host's collect output in `~/.cache/proj/<host>.json` and drives fzf.

**Tech Stack:** Python ≥ 3.8 stdlib only; git; fzf (Mac, `brew install fzf`); osascript + iTerm2; pytest for tests.

**Spec:** `docs/superpowers/specs/2026-10-16-projdeck-design.md`

## Global Constraints

- Python ≥ 3.8, **standard library only** in `projdeck/` (no f-string `=` specifier, no `match`, no `str.removeprefix`, no `tomllib`, no walrus).
- `projdeck/agent.py` must never import other `projdeck` modules (it is sent to remote hosts as a single file).
- Config file: `~/.config/proj/config.json` (override with env `PROJ_CONFIG`); cache dir `~/.cache/proj` (env `PROJ_CACHE`); trash dir `~/.proj-trash`.
- Tiers: active < 14 days, stale < 90 days, else abandoned; non-existent dir = deleted.
- Git commands timeout 5 s each; SSH agent run timeout 20 s (`ssh_timeout`).
- Cleanup never deletes: only moves untracked, non-ignored files into the trash dir with a `manifest.json`; only `purge` deletes and requires typing `yes`.
- Agent output uses `json.dumps` with default `ensure_ascii=True` (remote locale may be C).
- Commits: `git -c user.name=xmxurey -c user.email=xmxurey@gmail.com commit ...`, message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Deviations from spec (decided while planning)

- Spec's `collect.py` is named `agent.py` and also hosts the cleanup actions, so the remote side is one file (DRY).
- Session parsing scans whole JSONL files with cheap substring/regex filters instead of head/tail reads, because `custom-title` / `ai-title` records can appear anywhere in the file. `n_msgs` is replaced by `size_kb`; a `headless` flag marks `entrypoint == "sdk-cli"` (cron/SDK) sessions, and "resume latest" prefers non-headless ones.
- Cleanup candidates come from `git status --porcelain -z --untracked-files=all` (file level; ignored files excluded), equivalent to `git clean -nd` but per file.
- Non-git direct children of a root (e.g. `~/airdrop`) are included as "plain" projects (`include_plain`, default true) so stale non-repo dirs show up.
- `proj trash` without `--purge` lists batches.
- Suspicious patterns match any path component, so files inside an untracked `scratch/` or `tmp*/` dir are flagged.
- Trash batch layout is `<ts>-<project>/<rel>`.
- The file picker has no content preview.
- The stale-host warning appears in the preview pane.
- `clean` only works on a repository root (not a subdirectory or a plain directory).
- Home folders (Library, Applications, Movies, Music, Pictures, Public, Desktop, Documents, Downloads) are skipped when a root is `~`.

```python
#!/usr/bin/env python3
"""projdeck agent: runs on every host and answers one JSON request.

Standalone on purpose (stdlib only, Python >= 3.8, no projdeck imports),
because it is piped to remote hosts:
    ssh HOST python3 - '<json request>' < agent.py
"""
import fnmatch
import json
import os
import re
import shutil
import socket
import subprocess
import sys
import time

SCHEMA = 1
SKIP_DIRS = {".git", "node_modules", ".venv", "venv", "target", "dist", "build",
             "__pycache__", ".mypy_cache", ".pytest_cache", ".tox", ".next"}
DEFAULT_PATTERNS = ["test_*.py", "*_backup*", "*.bak", "*.log", "*SUMMARY*.md",
                    "*IMPLEMENTATION*.md", "*REPORT*.md", "crontab-backup*",
                    "tmp*", "scratch*", "*.orig", "*_v2.*", "*_old.*"]
TEST_DIRS = {"tests", "test"}
MAX_FILES = 5000
GIT_TIMEOUT = 5
TRASH_DIR = "~/.proj-trash"


def git(path, *args):
    r = subprocess.run(["git", "-C", path] + list(args), stdout=subprocess.PIPE,
                       stderr=subprocess.PIPE, timeout=GIT_TIMEOUT)
    if r.returncode != 0:
        raise RuntimeError(r.stderr.decode("utf-8", "replace").strip() or "git failed")
    return r.stdout.decode("utf-8", "replace")


def is_repo(path):
    return os.path.exists(os.path.join(path, ".git"))


def parse_status(out):
    """Parse `git status --porcelain=v1 -b -z` into (info, untracked_paths)."""
    entries = out.split("\0")
    info = {"branch": None, "dirty": 0, "untracked": 0, "ahead": 0, "no_upstream": True}
    untracked = []
    i = 0
    while i < len(entries):
        e = entries[i]
        i += 1
        if not e:
            continue
        if e.startswith("## "):
            head = e[3:]
            if head.startswith("No commits yet on "):
                info["branch"] = head[len("No commits yet on "):]
                continue
            name, sep, rest = head.partition("...")
            info["branch"] = name.split(" ")[0]
            if sep:
                info["no_upstream"] = False
                m = re.search(r"ahead (\d+)", rest)
                if m:
                    info["ahead"] = int(m.group(1))
            continue
        xy, path = e[:2], e[3:]
        if xy == "??":
            untracked.append(path)
        else:
            info["dirty"] += 1
            if xy[0] in "RC":
                i += 1  # rename/copy: the next entry is the source path
    info["untracked"] = len(untracked)
    return info, untracked


def git_info(path):
    out = git(path, "status", "--porcelain=v1", "-b", "-z", "--untracked-files=all")
    info, untracked = parse_status(out)
    try:
        info["last_commit_ts"] = int(git(path, "log", "-1", "--format=%ct").strip() or 0)
    except RuntimeError:
        info["last_commit_ts"] = 0  # no commits yet
    return info, untracked


def is_suspicious(relpath, patterns):
    parts = relpath.rstrip("/").split("/")
    if fnmatch.fnmatchcase(parts[-1], "test_*.py") and TEST_DIRS & set(parts[:-1]):
        return False
    return any(fnmatch.fnmatchcase(part, pat) for part in parts for pat in patterns)


def last_mtime(path, max_files=MAX_FILES):
    newest = 0.0
    seen = 0
    for dirpath, dirnames, filenames in os.walk(path):
        dirnames[:] = [d for d in dirnames if d not in SKIP_DIRS]
        for fn in filenames:
            try:
                newest = max(newest, os.lstat(os.path.join(dirpath, fn)).st_mtime)
            except OSError:
                pass
            seen += 1
            if seen >= max_files:
                return int(newest)
    return int(newest)


def progress(path, repo):
    pf = os.path.join(path, "PROGRESS.md")
    if os.path.isfile(pf):
        with open(pf, encoding="utf-8", errors="replace") as f:
            lines = [line.rstrip() for _, line in zip(range(10), f)]
        return "\n".join(line for line in lines if line.strip())
    if repo:
        try:
            return git(path, "log", "-3", "--format=%s").strip()
        except RuntimeError:
            return ""
    return ""


def _subdirs(d):
    try:
        names = sorted(os.listdir(d))
    except OSError:
        return []
    out = []
    for n in names:
        sub = os.path.join(d, n)
        if not n.startswith(".") and n not in SKIP_DIRS and os.path.isdir(sub) \
                and not os.path.islink(sub):
            out.append(sub)
    return out


def discover(roots, depth, include_plain=True):
    """Git repos under roots (not descending into repos) plus, optionally,
    non-git direct children of a root that contain no repo."""
    found = []

    def walk(d, level):
        if is_repo(d):
            found.append(d)
            return True
        hit = False
        if level < depth:
            for sub in _subdirs(d):
                hit = walk(sub, level + 1) or hit
        if level == 1 and not hit and include_plain:
            found.append(d)
        return hit

    for r in roots:
        r = os.path.abspath(os.path.expanduser(r))
        if os.path.isdir(r):
            walk(r, 0)
    return sorted(set(found))
```

```python
CWD_RE = re.compile(r'"cwd":"((?:[^"\\]|\\.)*)"')
ENTRY_RE = re.compile(r'"entrypoint":"([^"]*)"')


def _text_of(message):
    content = (message or {}).get("content") if isinstance(message, dict) else None
    if isinstance(content, str):
        return content
    if isinstance(content, list):
        for block in content:
            if isinstance(block, dict) and block.get("type") == "text":
                return block.get("text") or ""
    return ""


def one_line(s, n=80):
    return " ".join(s.split())[:n]


def parse_session(fp):
    """Summarise one Claude Code transcript. The JSONL format is internal and
    changes between versions, so every field is optional and bad lines are skipped."""
    sid = os.path.basename(fp)[:-len(".jsonl")]
    cwd = entry = custom = ai = first = None
    with open(fp, encoding="utf-8", errors="replace") as f:
        for line in f:
            if cwd is None:
                m = CWD_RE.search(line)
                if m:
                    try:
                        cwd = json.loads('"%s"' % m.group(1))
                    except ValueError:
                        pass
            if entry is None:
                m = ENTRY_RE.search(line)
                if m:
                    entry = m.group(1)
            if '"type":"custom-title"' in line or '"type":"ai-title"' in line:
                try:
                    d = json.loads(line)
                except ValueError:
                    continue
                if d.get("type") == "custom-title" and d.get("customTitle"):
                    custom = d["customTitle"]
                elif d.get("type") == "ai-title" and d.get("aiTitle"):
                    ai = d["aiTitle"]
            elif first is None and '"type":"user"' in line:
                try:
                    d = json.loads(line)
                except ValueError:
                    continue
                text = _text_of(d.get("message")) if d.get("type") == "user" else ""
                if text.strip() and not text.lstrip().startswith("<"):
                    first = text
    if cwd is None:
        return None
    st = os.stat(fp)
    title = custom or ai or (one_line(first) if first else "") or "(untitled)"
    return {"id": sid, "cwd": cwd, "title": one_line(title), "last_ts": int(st.st_mtime),
            "size_kb": st.st_size // 1024, "headless": entry == "sdk-cli"}


def scan_sessions(claude_dir):
    base = os.path.join(os.path.expanduser(claude_dir), "projects")
    out = []
    try:
        dirs = sorted(os.listdir(base))
    except OSError:
        return out
    for d in dirs:
        pd = os.path.join(base, d)
        if not os.path.isdir(pd):
            continue
        for fn in sorted(os.listdir(pd)):
            if not fn.endswith(".jsonl"):
                continue

                s = parse_session(os.path.join(pd, fn))
            except OSError:

def owner(cwd, paths):
    best = None
    for p in paths:
        if cwd == p or cwd.startswith(p.rstrip("/") + "/"):
            if best is None or len(p) > len(best):
                best = p
    return best


def project_root_for(cwd):
    if os.path.isdir(cwd):
        try:
            return git(cwd, "rev-parse", "--show-toplevel").strip() or cwd
        except Exception:
            pass
    return cwd


def build_project(path, patterns):
    p = {"path": path, "exists": os.path.isdir(path), "git": None, "last_mtime": 0,
         "suspicious": [], "progress": "", "sessions": [], "errors": []}
    if not p["exists"]:
        return p
    repo = is_repo(path)
    try:
        p["last_mtime"] = last_mtime(path)
    except Exception as e:
        p["errors"].append("mtime: %s" % e)
    if repo:
        try:
            info, untracked = git_info(path)
            p["git"] = info
            p["suspicious"] = [u for u in untracked if is_suspicious(u, patterns)]
        except Exception as e:
            p["errors"].append("git: %s" % e)
    try:
        p["progress"] = progress(path, repo)
    except Exception as e:
        p["errors"].append("progress: %s" % e)
    return p


def collect(req):
    patterns = req.get("patterns") or DEFAULT_PATTERNS
    paths = discover(req.get("roots") or ["~"], int(req.get("scan_depth", 2)),
                     bool(req.get("include_plain", True)))
    sessions = scan_sessions(req.get("claude_dir") or "~/.claude")
    for s in sessions:
        if owner(s["cwd"], paths) is None:
            paths.append(project_root_for(s["cwd"]))  # known only through its sessions
    projects = {path: build_project(path, patterns) for path in paths}
    for s in sessions:
        projects[owner(s["cwd"], list(projects))]["sessions"].append(s)
    for p in projects.values():
        p["sessions"].sort(key=lambda s: -s["last_ts"])
    return {"schema": SCHEMA,
            "host": req.get("host") or socket.gethostname().split(".")[0],
            "collected_at": int(time.time()),
            "projects": sorted(projects.values(), key=lambda p: p["path"])}

    sys.stdout.flush()
```

```python
def _trash_root(req):
    return os.path.expanduser(req.get("trash_dir") or TRASH_DIR)


def _write_manifest(batch_dir, manifest):
    tmp = os.path.join(batch_dir, "manifest.json.tmp")
    with open(tmp, "w") as f:
        json.dump(manifest, f)
    os.replace(tmp, os.path.join(batch_dir, "manifest.json"))


def act_list(req):
    path = os.path.abspath(os.path.expanduser(req["path"]))
    patterns = req.get("patterns") or DEFAULT_PATTERNS
    _, untracked = git_info(path)
    files = []
    for rel in untracked:
        try:
            size = os.lstat(os.path.join(path, rel)).st_size
        except OSError:
            size = 0
        files.append({"path": rel, "suspicious": is_suspicious(rel, patterns), "size": size})
    return {"path": path, "files": files}


def act_trash(req):
    path = os.path.abspath(os.path.expanduser(req["path"]))
    now = req.get("now") or time.time()
    current = set(git_info(path)[1])  # re-check: only still-untracked, non-ignored files
    root = _trash_root(req)
    base_id = time.strftime("%Y%m%d-%H%M%S", time.localtime(now)) + "-" + os.path.basename(path)
    batch_id, n = base_id, 1
    while os.path.exists(os.path.join(root, batch_id)):
        n += 1
        batch_id = "%s-%d" % (base_id, n)
    batch_dir = os.path.join(root, batch_id)
    manifest = {"created": int(now), "project": path, "items": []}
    skipped = []
    for rel in req.get("files", []):
        src = os.path.normpath(os.path.join(path, rel))
        if os.path.isabs(rel) or not src.startswith(path + os.sep) or rel not in current:
            skipped.append(rel)
            continue
        dst = os.path.join(batch_dir, rel)
        os.makedirs(os.path.dirname(dst), exist_ok=True)
        shutil.move(src, dst)
        manifest["items"].append({"src": src, "dst": dst})
        _write_manifest(batch_dir, manifest)  # after every move, so a crash loses nothing
    moved = [it["src"] for it in manifest["items"]]
    return {"batch": batch_id if moved else None, "moved": moved, "skipped": skipped}


def _load_batches(root):
    out = []
    if not os.path.isdir(root):
        return out
    for name in sorted(os.listdir(root)):
        try:
            with open(os.path.join(root, name, "manifest.json")) as f:
                m = json.load(f)
        except (OSError, ValueError):
            continue
        out.append({"id": name, "created": m["created"], "project": m["project"],
                    "count": len(m["items"])})
    return out


def act_batches(req):
    return {"batches": _load_batches(_trash_root(req))}


def act_restore(req):
    batch_id = req["batch"]
    if "/" in batch_id or batch_id in ("", ".", ".."):
        raise ValueError("bad batch id %r" % batch_id)
    batch_dir = os.path.join(_trash_root(req), batch_id)
    with open(os.path.join(batch_dir, "manifest.json")) as f:
        manifest = json.load(f)
    restored, skipped, remaining = [], [], []
    for it in manifest["items"]:
        if os.path.lexists(it["src"]) or not os.path.lexists(it["dst"]):
            skipped.append(it["src"])
            remaining.append(it)
            continue
        os.makedirs(os.path.dirname(it["src"]), exist_ok=True)
        shutil.move(it["dst"], it["src"])
        restored.append(it["src"])
    if remaining:
        manifest["items"] = remaining
        _write_manifest(batch_dir, manifest)
    else:
        shutil.rmtree(batch_dir)
    return {"restored": restored, "skipped": skipped}


def act_purge(req):
    root = _trash_root(req)
    cutoff = (req.get("now") or time.time()) - float(req["older_days"]) * 86400
    purged = []
    for b in _load_batches(root):
        if b["created"] < cutoff:
            shutil.rmtree(os.path.join(root, b["id"]))
            purged.append(b["id"])
    return {"purged": purged}


ACTIONS = {"collect": collect, "list": act_list, "trash": act_trash,
           "batches": act_batches, "restore": act_restore, "purge": act_purge}
```

```python
"""Run the agent on each host (locally or over ssh) and cache the results."""
import json
import os
import shlex
import subprocess
import sys
import time
from concurrent.futures import ThreadPoolExecutor

from projdeck import agent
from projdeck.config import collector_request

AGENT_PATH = os.path.abspath(agent.__file__)


class AgentError(Exception):
    pass


def cache_dir():
    return os.path.expanduser(os.environ.get("PROJ_CACHE", "~/.cache/proj"))


def _argv(host, req):
    payload = json.dumps(req)
    if host.get("local"):
        return [sys.executable, AGENT_PATH, payload], None
    with open(AGENT_PATH, "rb") as f:
        script = f.read()
    return (["ssh", "-o", "BatchMode=yes", "-o", "ConnectTimeout=10", host["ssh"],
             "python3 - " + shlex.quote(payload)], script)


def run_agent(host, req, timeout=20):
    argv, stdin = _argv(host, req)
    try:
        r = subprocess.run(argv, input=stdin, stdout=subprocess.PIPE, stderr=subprocess.PIPE,
                           timeout=timeout)
    except subprocess.TimeoutExpired:
        raise AgentError("timed out after %ss" % timeout)
    except OSError as e:
        raise AgentError(str(e))
    try:
        result = json.loads(r.stdout.decode("utf-8", "replace"))
    except ValueError:
        err = r.stderr.decode("utf-8", "replace").strip() or "no output (exit %d)" % r.returncode
        raise AgentError(err[-300:])
    if isinstance(result, dict) and "error" in result:
        raise AgentError(result["error"])
    return result


def _cache_path(name):
    return os.path.join(cache_dir(), name + ".json")


def read_cache(name):
    try:
        with open(_cache_path(name)) as f:
            return json.load(f)
    except (OSError, ValueError):
        return None


def _write_cache(name, data):
    os.makedirs(cache_dir(), exist_ok=True)

def sync_host(host, cfg, now=None):
    now = int(now or time.time())
    try:
        data = run_agent(host, collector_request(cfg, host), timeout=cfg["ssh_timeout"])
        if data.get("schema") != agent.SCHEMA:
            raise AgentError("schema %r != %d, update projdeck" % (data.get("schema"), agent.SCHEMA))
        data.update(host=host["name"], synced_at=now, stale_since=None, last_error=None)
        _write_cache(host["name"], data)
        return {"host": host["name"], "ok": True, "error": None}
    except AgentError as e:
        old = read_cache(host["name"])
        if old:
            old["stale_since"] = old.get("stale_since") or old.get("synced_at") or now
            old["last_error"] = str(e)
            _write_cache(host["name"], old)
        return {"host": host["name"], "ok": False, "error": str(e)}


def sync_all(cfg, names=None):
    hosts = [h for h in cfg["hosts"] if not names or h["name"] in names]
    if not hosts:
        return []
    with ThreadPoolExecutor(max_workers=len(hosts)) as ex:
        return list(ex.map(lambda h: sync_host(h, cfg), hosts))


def load_caches(cfg):
    caches = [read_cache(h["name"]) for h in cfg["hosts"]]
    return [c for c in caches if c]


def oldest_sync(cfg):
    stamps = []
    for h in cfg["hosts"]:
        c = read_cache(h["name"])
        if not c:
            return None
        stamps.append(c.get("synced_at") or 0)
    return min(stamps) if stamps else None
```

```python
"""Turn per-host caches into one sorted list of project rows."""
TIER_ICON = {"active": "●", "stale": "◐", "abandoned": "○", "deleted": "✗"}


def last_activity(p):
    stamps = [p.get("last_mtime") or 0] + [s["last_ts"] for s in p.get("sessions", [])]
    if p.get("git"):
        stamps.append(p["git"].get("last_commit_ts") or 0)
    return max(stamps)


def tier(p, now, tiers_days):
    if not p.get("exists", True):
        return "deleted"
    age_days = (now - last_activity(p)) / 86400.0
    if age_days < tiers_days["active"]:
        return "active"
    if age_days < tiers_days["stale"]:
        return "stale"
    return "abandoned"


def rows(caches, cfg, now):
    hosts = {h["name"]: h for h in cfg["hosts"]}
    out = []
    for c in caches:
        h = hosts.get(c["host"], {"ssh": c["host"]})
        for p in c["projects"]:
            r = dict(p)
            r.update(host=c["host"], local=bool(h.get("local")), ssh=h.get("ssh"),
                     activity=last_activity(p), tier=tier(p, now, cfg["tiers_days"]),
                     stale_since=c.get("stale_since"))
            out.append(r)
    out.sort(key=lambda r: -r["activity"])
    return out


def find_row(rows_, host, path):
    for r in rows_:
        if r["host"] == host and r["path"] == path:
            return r
    return None


def all_sessions(rows_):
    pairs = [(r, s) for r in rows_ for s in r["sessions"]]
    pairs.sort(key=lambda pair: -pair[1]["last_ts"])
    return pairs


def latest_session(row):
    sessions = row["sessions"]
    for s in sessions:
        if not s.get("headless"):
            return s
    return sessions[0] if sessions else None


def human_age(seconds):
    s = max(0, int(seconds))
    for unit, n in (("y", 365 * 86400), ("mo", 30 * 86400), ("d", 86400), ("h", 3600),
                    ("m", 60)):
        if s >= n:
            return "%d%s" % (s // n, unit)
    return "now"
```

```python
def render(rows, caches, now):

        out.extend(items or ["- none"])

    git_rows = [r for r in rows if r.get("git")]
    section("Uncommitted / unpushed", [
        "- %s ±%d ↑%d" % (_key(r), r["git"]["dirty"], r["git"]["ahead"])
        for r in git_rows if r["git"]["dirty"] or r["git"]["ahead"]])
    section("No upstream branch", ["- %s" % _key(r) for r in git_rows if r["git"]["no_upstream"]])
    susp = sorted((r for r in rows if r["suspicious"]), key=lambda r: -len(r["suspicious"]))

        "- %s %d files: %s" % (_key(r), len(r["suspicious"]), ", ".join(r["suspicious"][:5]))
        for r in susp[:15]])

                          for r in rows if r["tier"] == "abandoned"])
    section("Deleted (sessions point to missing dirs)",
            ["- %s" % _key(r) for r in rows if r["tier"] == "deleted"])
```

```python
"""Build the shell command for a project/session and open it in iTerm2."""
import os
import shlex
import subprocess
import sys

q = shlex.quote
LOGIN_SHELL = 'exec "$SHELL" -l'


def resume_inner(session_id):
    return "claude --resume %s" % q(session_id)


def _remote_script(path, inner):
    if inner is None:
        return "cd %s && %s" % (q(path), LOGIN_SHELL)
    # login + interactive so PATH (claude) is set; keep a shell open afterwards
    return 'cd %s && "$SHELL" -lic %s; %s' % (q(path), q(inner), LOGIN_SHELL)


def build_command(target, path, inner=None, new_tab=True):
    if target.get("local"):
        if inner is None and not new_tab:
            inner = LOGIN_SHELL
        return "cd %s" % q(path) + (" && %s" % inner if inner else "")
    return "ssh -t %s %s" % (q(target["ssh"]), q(_remote_script(path, inner)))


def _as_str(s):
    return '"%s"' % s.replace("\\", "\\\\").replace('"', '\\"')


def applescript(cmd, title):
    return "\n".join([
        'tell application "iTerm2"',
        "  activate",
        "  if (count of windows) = 0 then",
        "    create window with default profile",
        "  else",
        "    tell current window to create tab with default profile",
        "  end if",
        "  tell current session of current window",
        "    set name to %s" % _as_str(title),
        "    write text %s" % _as_str(cmd),
        "  end tell",
        "end tell",
    ])


def has_iterm():
    return sys.platform == "darwin" and any(
        os.path.isdir(p) for p in ("/Applications/iTerm.app",
                                   os.path.expanduser("~/Applications/iTerm.app")))


def open_command(cmd, title, run=subprocess.run, iterm=None):
    if iterm is None:
        iterm = has_iterm()
    if iterm:
        run(["osascript", "-e", applescript(cmd, title)], check=True)
        return "iterm"
    run(cmd, shell=True)  # no iTerm2: run in the current terminal
    return "inline"
```

```python
from projdeck.model import TIER_ICON, human_age

SEP = "\t"
PROJECT_KEYS = ["ctrl-r", "ctrl-s", "ctrl-x", "ctrl-u"]
PROJECT_HEADER = "Enter: open · ^R: resume latest · ^S: pick session · ^X: clean · ^U: sync"


class Cancelled(Exception):
    pass


def run_fzf(lines, args, expect=()):
    argv = ["fzf"] + list(args)
    if expect:
        argv.append("--expect=" + ",".join(expect))
    try:
        r = subprocess.run(argv, input="\n".join(lines), stdout=subprocess.PIPE,
                           universal_newlines=True)
    except FileNotFoundError:
        raise SystemExit("fzf is required: brew install fzf")
    if r.returncode != 0:
        raise Cancelled()
    out = r.stdout.split("\n")
    key = out.pop(0) if expect else ""
    return key, [line for line in out if line]


def preview_cmd():
    return "%s -m projdeck _preview {1} {2}" % shlex.quote(sys.executable)


def _name(path):
    return os.path.basename(path.rstrip("/")) or path


def project_line(r, now):
    g = r.get("git") or {}
    flags = []
    if g.get("dirty"):
        flags.append("±%d" % g["dirty"])
    if g.get("ahead"):
        flags.append("↑%d" % g["ahead"])
    if r.get("git") and g.get("no_upstream"):
        flags.append("⊘")
    if r["suspicious"]:
        flags.append("⚑%d" % len(r["suspicious"]))
    if r["sessions"]:
        flags.append("💬%d" % len(r["sessions"]))
    if not r.get("git") and r["exists"]:
        flags.append("non-git")
    display = "%-8s %s %-28s %5s  %s" % (r["host"][:8], TIER_ICON[r["tier"]], _name(r["path"])[:28],
                                         human_age(now - r["activity"]), " ".join(flags))
    return SEP.join([r["host"], r["path"], display])


def session_line(r, s, now):
    display = "%-8s %5s  %-20s %s%s" % (r["host"][:8], human_age(now - s["last_ts"]),
                                        _name(r["path"])[:20], s["title"],
                                        "  [headless]" if s.get("headless") else "")
    return SEP.join([r["host"], r["path"], s["id"], display])


def file_line(f):
    return SEP.join([f["path"], "%s %s  (%dK)" % ("⚑" if f["suspicious"] else " ", f["path"],
                                                   f["size"] // 1024)])


def preview_text(r, now):
    out = ["%s:%s" % (r["host"], r["path"]),
           "%s %s · last activity %s ago" % (TIER_ICON[r["tier"]], r["tier"],
                                             human_age(now - r["activity"]))]
    if r.get("stale_since"):
        out.append("⚠ host data is from %s ago (last sync failed)" % human_age(now - r["stale_since"]))
    g = r.get("git")
    if g:
        out.append("git: %s  ±%d ↑%d  untracked %d%s  last commit %s ago" % (
            g["branch"], g["dirty"], g["ahead"], g["untracked"],
            "  (no upstream)" if g["no_upstream"] else "", human_age(now - g["last_commit_ts"])))
    elif r["exists"]:
        out.append("not a git repo")
    else:
        out.append("directory no longer exists")
    if r["suspicious"]:
        out.append("")
        out.append("suspicious files (%d):" % len(r["suspicious"]))
        out.extend("  " + s for s in r["suspicious"][:10])
    if r["progress"]:
        out.extend(["", "progress:"] + ["  " + line for line in r["progress"].splitlines()])
    if r["sessions"]:
        out.extend(["", "sessions (%d):" % len(r["sessions"])])
        for s in r["sessions"][:8]:
            out.append("  %5s  %s%s" % (human_age(now - s["last_ts"]), s["title"],
                                        "  [headless]" if s.get("headless") else ""))
    if r.get("errors"):
        out.extend(["", "errors:"] + ["  " + e for e in r["errors"]])
    return "\n".join(out)


def pick_project(rows, now):
    lines = [project_line(r, now) for r in rows]
    key, sel = run_fzf(lines, ["--delimiter=\t", "--with-nth=3..", "--tiebreak=index",
                               "--header=" + PROJECT_HEADER, "--preview=" + preview_cmd(),
                               "--preview-window=right,50%,wrap"], expect=PROJECT_KEYS)
    if not sel:
        raise Cancelled()
    host, path, _ = sel[0].split(SEP, 2)
    return key, host, path


def pick_session(pairs, now):
    lines = [session_line(r, s, now) for r, s in pairs]
    _, sel = run_fzf(lines, ["--delimiter=\t", "--with-nth=4..", "--tiebreak=index",
                             "--header=Enter: resume in a new tab",
                             "--preview=" + preview_cmd(), "--preview-window=right,40%,wrap"])
    if not sel:
        raise Cancelled()
    host, path, sid, _ = sel[0].split(SEP, 3)
    return host, path, sid


def pick_files(files):
    files = sorted(files, key=lambda f: (not f["suspicious"], f["path"]))
    k = sum(1 for f in files if f["suspicious"])
    args = ["--multi", "--layout=reverse", "--delimiter=\t", "--with-nth=2..",
            "--header=Tab: toggle · Enter: confirm (⚑ = matches junk rules, preselected)"]
    if k:
        args.append("--bind=start:" + "+".join(["toggle+down"] * k) + "+first")
    _, sel = run_fzf([file_line(f) for f in files], args)
    return [line.split(SEP, 1)[0] for line in sel]


def pick_line(lines, header):
    _, sel = run_fzf(lines, ["--header=" + header, "--layout=reverse"])
    if not sel:
        raise Cancelled()
    return sel[0]


def fmt_time(ts):
    return time.strftime("%Y-%m-%d %H:%M", time.localtime(ts))
```

```python
"""`proj` command line."""
import argparse
import os
import subprocess
import sys
import time

from projdeck import config, model, opener, report, sync, ui

REPO_ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))


def _env_setup():
    # children (fzf preview, background sync) run `python -m projdeck`
    parts = [REPO_ROOT] + [p for p in os.environ.get("PYTHONPATH", "").split(os.pathsep) if p]
    os.environ["PYTHONPATH"] = os.pathsep.join(parts)


def print_sync(status):
    for s in status:
        print("%s: %s" % (s["host"], "ok" if s["ok"] else "FAILED (%s)" % s["error"]))


def background_sync():
    marker = os.path.join(sync.cache_dir(), ".syncing")
    try:
        if time.time() - os.path.getmtime(marker) < 300:
            return
    except OSError:
        pass
    os.makedirs(sync.cache_dir(), exist_ok=True)
    with open(marker, "w"):
        pass
    subprocess.Popen([sys.executable, "-m", "projdeck", "sync", "--quiet"],
                     stdin=subprocess.DEVNULL, stdout=subprocess.DEVNULL,
                     stderr=subprocess.DEVNULL, start_new_session=True)


def fresh_caches(cfg, now):
    oldest = sync.oldest_sync(cfg)
    if oldest is None:
        print("first sync…", file=sys.stderr)
        print_sync(sync.sync_all(cfg))
    elif now - oldest > cfg["auto_sync_minutes"] * 60:
        background_sync()
    return sync.load_caches(cfg)


def launch(row, path, session=None):
    new_tab = opener.has_iterm()
    inner = opener.resume_inner(session["id"]) if session else None
    cmd = opener.build_command(row, path, inner, new_tab=new_tab)
    title = "%s:%s" % (row["host"], os.path.basename(path.rstrip("/")))
    opener.open_command(cmd, title, iterm=new_tab)
    return 0


def cmd_browse(cfg, args):
    now = time.time()
    caches = fresh_caches(cfg, now)
    while True:
        rows = model.rows(caches, cfg, now)
        if not rows:
            print("no projects found; check roots in %s" % config.config_path())
            return 1
        try:
            key, host, path = ui.pick_project(rows, now)
        except ui.Cancelled:
            return 0
        r = model.find_row(rows, host, path)
        if key == "ctrl-u":
            print_sync(sync.sync_all(cfg))
            caches, now = sync.load_caches(cfg), time.time()
            continue
        if key == "ctrl-x":
            return clean(cfg, host, path)
        if key == "ctrl-r":
            s = model.latest_session(r)
            if s is None:
                print("no sessions for this project")
                continue
            return launch(r, s["cwd"], s)
        if key == "ctrl-s":
            if not r["sessions"]:
                print("no sessions for this project")
                continue
            try:
                _, _, sid = ui.pick_session([(r, s) for s in r["sessions"]], now)
            except ui.Cancelled:
                continue
            s = next(s for s in r["sessions"] if s["id"] == sid)
            return launch(r, s["cwd"], s)
        if not r["exists"]:
            print("directory no longer exists: %s" % path)
            continue
        return launch(r, path)


def cmd_sessions(cfg, args):
    now = time.time()
    rows = model.rows(fresh_caches(cfg, now), cfg, now)
    try:
        host, path, sid = ui.pick_session(model.all_sessions(rows), now)
    except ui.Cancelled:
        return 0
    r = model.find_row(rows, host, path)
    s = next(s for s in r["sessions"] if s["id"] == sid)
    return launch(r, s["cwd"], s)


def cmd_sync(cfg, args):
    status = sync.sync_all(cfg, args.hosts or None)
    if not args.quiet:
        print_sync(status)
    try:
        os.remove(os.path.join(sync.cache_dir(), ".syncing"))
    except OSError:
        pass
    return 0 if all(s["ok"] for s in status) else 1


def cmd_report(cfg, args):
    now = time.time()
    caches = sync.load_caches(cfg)
    sys.stdout.write(report.render(model.rows(caches, cfg, now), caches, now))
    return 0


def clean(cfg, host_name, path):
    host = config.host_by_name(cfg, host_name)
    listing = sync.run_agent(host, {"action": "list", "path": path,
                                    "patterns": cfg["suspicious_patterns"]}, cfg["ssh_timeout"])
    if not listing["files"]:
        print("no untracked files in %s:%s" % (host_name, path))
        return 0
    try:
        chosen = ui.pick_files(listing["files"])
    except ui.Cancelled:
        return 0
    if not chosen:
        return 0
    print("\n".join("  " + c for c in chosen))
    if input("move %d file(s) to %s on %s? [y/N] " % (len(chosen), cfg["trash_dir"], host_name)) \
            .strip().lower() != "y":
        return 0
    res = sync.run_agent(host, {"action": "trash", "path": path, "files": chosen,
                                "trash_dir": cfg["trash_dir"]}, cfg["ssh_timeout"])
    print("moved %d, skipped %d%s" % (len(res["moved"]), len(res["skipped"]),
                                       ("  (batch %s; undo: proj restore)" % res["batch"])
                                       if res["batch"] else ""))
    for s in res["skipped"]:
        print("  skipped (no longer untracked or unsafe): %s" % s)
    return 0


def cmd_clean(cfg, args):
    host, sep, path = args.target.partition(":")
    if not sep:
        raise SystemExit("usage: proj clean HOST:PATH")
    return clean(cfg, host, path)


def _all_batches(cfg, host_name):
    hosts = [config.host_by_name(cfg, host_name)] if host_name else cfg["hosts"]
    out = []
    for h in hosts:
        try:
            res = sync.run_agent(h, {"action": "batches", "trash_dir": cfg["trash_dir"]},
                                 cfg["ssh_timeout"])
        except sync.AgentError as e:
            print("%s: %s" % (h["name"], e), file=sys.stderr)
            continue
        out.extend((h, b) for b in res["batches"])
    return out


def _batch_line(h, b):
    return "%s\t%s\t%s  %d file(s)  %s" % (h["name"], b["id"], ui.fmt_time(b["created"]),
                                           b["count"], b["project"])


def cmd_restore(cfg, args):
    batches = _all_batches(cfg, args.host)
    if not batches:
        print("trash is empty")
        return 0
    try:
        line = ui.pick_line([_batch_line(h, b) for h, b in batches], "pick a batch to restore")
    except ui.Cancelled:
        return 0
    host_name, batch_id = line.split("\t")[:2]
    res = sync.run_agent(config.host_by_name(cfg, host_name),
                         {"action": "restore", "batch": batch_id, "trash_dir": cfg["trash_dir"]},
                         cfg["ssh_timeout"])
    print("restored %d, skipped %d" % (len(res["restored"]), len(res["skipped"])))
    for s in res["skipped"]:
        print("  skipped (path exists or trash copy missing): %s" % s)
    return 0


def _days(spec):
    spec = spec.strip().lower()
    return float(spec[:-1]) if spec.endswith("d") else float(spec)


def cmd_trash(cfg, args):
    batches = _all_batches(cfg, args.host)
    if not args.purge:
        for h, b in batches:
            print(_batch_line(h, b))
        return 0
    cutoff = time.time() - _days(args.older) * 86400
    old = [(h, b) for h, b in batches if b["created"] < cutoff]
    if not old:
        print("nothing older than %s" % args.older)
        return 0
    for h, b in old:
        print(_batch_line(h, b))
    print("%d batch(es) will be permanently deleted." % len(old))
    if input("type yes to confirm: ").strip() != "yes":
        return 0
    for h in {h["name"]: h for h, _ in old}.values():
        res = sync.run_agent(h, {"action": "purge", "older_days": _days(args.older),
                                 "trash_dir": cfg["trash_dir"]}, cfg["ssh_timeout"])
        print("%s: purged %d" % (h["name"], len(res["purged"])))
    return 0


def cmd_preview(cfg, args):
    now = time.time()
    r = model.find_row(model.rows(sync.load_caches(cfg), cfg, now), args.host.rstrip("\t"),
                       args.path.rstrip("\t"))
    print(ui.preview_text(r, now) if r else "(not in cache)")
    return 0


def parser():
    p = argparse.ArgumentParser(prog="proj", description="projects & Claude sessions across hosts")
    sub = p.add_subparsers(dest="cmd")
    sub.add_parser("sessions", help="search all sessions by title and resume one")
    s = sub.add_parser("sync", help="refresh data from all (or given) hosts")
    s.add_argument("hosts", nargs="*")
    s.add_argument("--quiet", action="store_true")
    sub.add_parser("report", help="markdown overview of what needs attention")
    s = sub.add_parser("clean", help="move untracked junk to the trash (reversible)")
    s.add_argument("target", metavar="HOST:PATH")
    s = sub.add_parser("restore", help="restore a trash batch")
    s.add_argument("host", nargs="?")
    s = sub.add_parser("trash", help="list trash batches, or --purge old ones")
    s.add_argument("--purge", action="store_true")
    s.add_argument("--older", default="30d")
    s.add_argument("host", nargs="?")
    s = sub.add_parser("_preview")
    s.add_argument("host")
    s.add_argument("path")
    return p


COMMANDS = {None: cmd_browse, "sessions": cmd_sessions, "sync": cmd_sync, "report": cmd_report,
            "clean": cmd_clean, "restore": cmd_restore, "trash": cmd_trash,
            "_preview": cmd_preview}


def main(argv=None):
    _env_setup()
    args = parser().parse_args(argv)
    try:
        cfg = config.load_config()
        return COMMANDS[args.cmd](cfg, args)
    except (ValueError, sync.AgentError) as e:
        print("proj: %s" % e, file=sys.stderr)
        return 2
```

````markdown
# projdeck (`proj`)

One place to see every project and Claude Code session on your Mac and SSH hosts,
jump into one in a new iTerm2 tab, and clean stray untracked files reversibly.

## Install (Mac)

```bash
brew install fzf
git clone <this repo> ~/dev/projdeck
ln -s ~/dev/projdeck/bin/proj /usr/local/bin/proj   # or any dir on PATH
```
Remote hosts need only `python3` and `git` (the agent is piped over ssh).

## Configure `~/.config/proj/config.json`

```json
{
  "hosts": [
    {"name": "mac", "local": true, "roots": ["~/dev"]},
    {"name": "sg",  "ssh": "sg",   "roots": ["~"]}
  ]
}
```
`ssh` is an alias from `~/.ssh/config` (key auth, `BatchMode`). Optional keys:
`tiers_days`, `scan_depth`, `include_plain`, `auto_sync_minutes`, `ssh_timeout`,
`suspicious_patterns`, `trash_dir`.

## Use

| command | what |
|---|---|
| `proj` | all projects; Enter open · ^R resume latest session · ^S pick session · ^X clean · ^U sync |
| `proj sessions` | search all sessions by title, resume |
| `proj sync [host…]` | refresh (auto in background after 30 min) |
| `proj report` | markdown: unpushed, no upstream, junk, abandoned, deleted |
| `proj clean HOST:PATH` | move untracked junk to `~/.proj-trash` (never ignored files) |
| `proj restore [host]` | put a batch back |
| `proj trash [--purge --older 30d]` | list / permanently delete old batches |

Tip: set `"cleanupPeriodDays": 365` in Claude Code settings, otherwise transcripts older
than 30 days are deleted and can't be listed.
````
