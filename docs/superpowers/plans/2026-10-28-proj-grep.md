# proj grep Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `proj grep [query]` searches every prompt the user typed in Claude Code sessions on all hosts and resumes the chosen session.

**Architecture:** The agent adds `prompts` (≤200 per session, each ≤300 chars, one line) to every session during sync, so prompts land in the existing per-host cache. `proj grep` turns cached prompts into fzf lines (one per prompt) and resumes via the existing `launch()`. A new hidden `_spreview` subcommand renders the preview.

**Tech Stack:** Python 3 stdlib, fzf ≥ 0.36, pytest.

## Global Constraints

- Agent stays stdlib-only, Python ≥ 3.8, no projdeck imports.
- `SCHEMA` unchanged; caches without `prompts` are treated as `[]`.
- Prompt filter = existing `_is_prompt` / tool_result exclusion; each prompt `one_line(text, 300)`; keep the **last** 200 per session.
- fzf defaults to `--exact`; optional query pre-filled with `--query=`.
- No prompts anywhere → print `no prompts cached; run proj sync`, exit 0.

```python
def spreview_cmd():
    return "%s -m projdeck _spreview {1} {2} {3} {4}" % shlex.quote(sys.executable)


def prompt_line(r, s, text, now):
    where = "%s:%s" % (r["host"], _name(r["path"]))
    display = "%5s  %-28s │ %s" % (human_age(now - s["last_ts"]), where[:28], text)
    return SEP.join([r["host"], r["path"], s["id"], text, display])


def _left_off(s, now):
    if not (s.get("recent") or s.get("last_reply")):
        return []
    out = ["", "left off · %s · %s ago" % (s["title"], human_age(now - s["last_ts"]))]
    out.extend("  › " + p for p in s.get("recent") or [])
    if s.get("last_reply"):
        out.append("  ⏺ " + s["last_reply"])
    return out


def session_preview_text(r, s, now, prompt):
    return "\n".join(["› " + prompt, "", "%s:%s" % (r["host"], r["path"]),
                      "session: %s · %s ago" % (s["title"], human_age(now - s["last_ts"]))]
                     + _left_off(s, now))


def pick_prompt(items, now, query=""):
    lines = [prompt_line(r, s, t, now) for r, s, t in items]
    args = ["--delimiter=\t", "--with-nth=5..", "--exact", "--tiebreak=index",
            "--header=Enter: resume in a new tab · 'word: fuzzy",
            "--preview=" + spreview_cmd(), "--preview-window=right,45%,wrap"]
    if query:
        args.append("--query=" + query)
    _, sel = run_fzf(lines, args)
    if not sel:
        raise Cancelled()
    host, path, sid, _ = sel[0].split(SEP, 3)
    return host, path, sid
```

```python
def cmd_grep(cfg, args):
    now = time.time()
    rows = model.rows(fresh_caches(cfg, now), cfg, now)
    items = model.all_prompts(rows)
    if not items:
        print("no prompts cached; run proj sync")
        return 0
    try:
        host, path, sid = ui.pick_prompt(items, now, " ".join(args.query))
    except ui.Cancelled:
        return 0
    r = model.find_row(rows, host, path)
    s = next(s for s in r["sessions"] if s["id"] == sid)
    launch(r, s["cwd"], s)
    return 0


def cmd_spreview(cfg, args):
    now = time.time()
    host, path, sid = (a.rstrip("\t") for a in (args.host, args.path, args.sid))
    caches = sync.load_caches(cfg)
    r = model.find_row(model.rows(caches, cfg, now), host, path)
    s = next((s for s in r["sessions"] if s["id"] == sid), None) if r else None
    print(ui.session_preview_text(r, s, now, args.prompt.rstrip("\t")) if s else "(not in cache)")
    return 0
```
